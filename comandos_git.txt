git init . -> Cria um repo git na pasta atual - Teste 01
git status -> mostra o status do trabalho - Teste 02
git add nome_arquivo -> adiciona arquivo para ser commitado - Teste 03
git commit -m "msg" -> faz commit do que estava para ser salvo
git log -> mostra todos o histórico de commit

## Fluxo de trabalho ##

1. criar o diretorio do projeto
2. iniciar o git dentro do diretório criado (git init .) - msg teste
3. edita ou cria arquivos
4. git status
5. git add <nome_arquivo>
6. git status
7. git commit -m "mensagem"
8. git status
9. volte para o passo 3
